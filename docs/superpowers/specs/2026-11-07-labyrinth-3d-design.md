# 3D 滚球迷宫（labyrinth-3d）设计

日期：2026-11-07 · 状态：已定稿，直接实施

## 命题

3D 专区已有 15 款，其中台球/保龄球是「平面上给初速度」，错视遗迹/立体井字是「轨道相机转格子」。
本作刻意避开两者：**相机固定，盘面自己倾斜**，玩法就是重力方向本身。
仓库内没有任何倾斜面物理，渲染与规则全部另写，零新依赖。

## 玩法

悬浮星盘上有一颗钢珠。拖拽（虚拟摇杆）或方向键倾斜盘面，钢珠沿重力在盘面上的投影加速滚动。
滚进金色终点洞过关；滚进 crimson 陷阱洞掉一条命，从起点或检查点重来。每关 3 条命，命尽结算。

递进机制：冰面（阻尼 ×0.28，刹不住）、沙地（阻尼 ×3.4，爬不动）、旋转摆杆（碰撞时把杆面线速度传给球，会甩飞）、
宝石（加分，可选路线）、检查点（掉命后从这里重来）。

## 物理

盘面局部坐标 x 右、y 出盘面、z 向屏幕近端。倾斜 = Rx(pitch) 后 Rz(roll)。
世界重力 (0,-g,0) 变到盘面局部后精确为 `(-g·sin r, -g·cos p·cos r, g·sin p·cos r)`，
故面内加速度 `ax = -g·sin r`、`az = g·sin p·cos r`（不是小角度近似，测试逐条钉符号）。

- g = 9.8，最大倾角 0.30 rad，倾斜速率上限 1.9 rad/s（满舵约 0.16 s，有实物感）
- 半隐式欧拉，固定子步 h = 1/240 s，帧 dt 夹到 0.05；限速 5.5 u/s ⇒ 单子步位移 ≤ 0.023 u，远小于墙厚，无隧穿
- 线性阻尼 k = 1.05 /s（终速约 2.75 u/s），冰面 ×0.28、沙地 ×3.4
- 墙：格子 AABB 最近点法，推出穿透 + 法向恢复系数 0.34 + 切向 ×0.88
- 洞：捕获阈值 `dist < holeR × 0.80`，边缘可碾过；捕获后进入 0.55 s 掉落动画，期间不接受输入
- 摆杆：胶囊（线段 + 半径）对圆，推出后叠加杆面线速度 ω×r

## 渲染

固定相机：yaw 0、elev 0.92 rad、距离 16；focal 由「最大倾角包络的 32 个角点」一次性拟合到视口，
不随每帧倾斜重算，避免画面抽动。

三遍，**standing 物件只有一个列表、只排序一次**（吸取打砖块遮挡反转那次教训）：
1. 盘体侧壁 + 顶面（地面）
2. 盘面贴花：冰/沙区、网格、洞、检查点、提示路径、宝石光晕、球接触阴影 —— 全部共面，
   按语义层序画（阴影最后，保证压在洞与地形之上），共面物之间不需要深度排序
3. 站立物：每格墙 boxes 的可见面（背面剔除后凸体各面互不重叠）、摆杆、宝石晶体、球、粒子，
   混在一个列表里按面/中心深度远→近画一次

球用径向渐变 + 高光 + 接触阴影；洞画投影椭圆 + 内壁暗边；终点洞金色脉动。
背景靛蓝星空沿用站点调色板（`--bg-0 #0f1222`、`--primary #7c5cff`、`--primary-2 #00d4ff`）。

## 输入

独立 Pointer 状态机：只左键；按下点为摇杆原点，位移按舞台尺寸归一化，死区 0.06，夹到 ±1；
松手回零。只跟踪一个 activePointerId，多余手指忽略。Ctrl/Cmd/Alt 一律不接管。
键盘方向键/WASD 按住给满舵，松手回零；R 重开、Enter 开始/下一关、Esc/P 暂停、H 提示。
`blur` 与 `visibilitychange(hidden)` 清按键与指针；输入框内不截键，Enter 落在按钮上交给原生点击。

## 成绩与落库

- meta：`id: 'labyrinth-3d'`、category `经典`、tags `['3D','物理','滚球','迷宫']`、`bestScoreLabel: '最高分'`、higherIsBetter
- 单关分 = 600 + 宝石×120 + 时间奖励 `max(0, round((par×1.6 - 用时)×20))` - 掉洞×120 - 提示×50
- 星：用时 ≤ par 三星、≤ par×1.6 两星、否则一星
- par 由自动驾驶与「8Hz 采样 + 0.15s 延迟 + ±22% 增益误差」的噪声人手模拟共同校准后写回 levels.ts
  （约为自动驾驶用时的 2.6 倍；实测八关自动驾驶 9.2~21.2s，噪声人手 12/12 通关），不手填
- run 分数跨关携带；**在过关与命尽两个离散结局点各结算一次最高分**（沿用宝石三消口径，不在每次加分时写档）
- 星级与解锁进度存 `pp:labyrinth:progress`（本地），上一关 ≥1 星即解锁下一关
- higherIsBetter ⇒ `functions/api/sync.js` 的 LOWER_BETTER 白名单无需改动
